# SPOTIFY-OUTPUT-001 — fizyczne wyjście oficjalnego Spotify

Status w rejestrze: Zrobione jako badanie historyczne. **Rekord odtworzony
16.11.2026 wyłącznie z `docs/zadania/README.md`; pierwotnego pełnego pliku
nie odnaleziono.**

## Zachowany wynik i późniejsza korekta

Rejestr stwierdzał brak potwierdzonego, wspieranego API do automatycznego
wyboru fizycznego wyjścia oficjalnej aplikacji Spotify. Ręczny wybór wyjścia
w Mikserze Windows nie był wdrożeniem `Shift+A`. Zapis o bieżącym Librespot
dotyczy starszej wersji AMC. Nowsze `SPOTIFY-CHROME-20261031.md` opisuje
Web Playback SDK w ukrytym Chrome i `Shift+A` dla tego toru. Ta późniejsza
decyzja zastępuje traktowanie Librespot jako aktualnego silnika AMC.

## Następny krok

Jeżeli powróci kwestia wyjścia w oficjalnej aplikacji Spotify, oddzielić ją
od wyjścia w odtwarzaczu AMC. Sprawdzić bieżącą dokumentację dostawcy i
stan działającego profilu, nie wyciągać wniosku z historycznego rejestru.
