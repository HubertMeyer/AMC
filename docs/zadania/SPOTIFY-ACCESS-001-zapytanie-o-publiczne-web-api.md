# SPOTIFY-ACCESS-001 — zapytanie o publiczne Spotify Web API

Status w rejestrze: Zrobione jako pakiet do recenzji, bez wysyłki.
**Rekord odtworzony 16.11.2026 wyłącznie z `docs/zadania/README.md`;
pierwotnego pełnego pliku ani pakietu zapytania nie odnaleziono pod tym
odsyłaczem.**

## Zachowany zakres

Przygotowano uczciwe wstępne zapytanie o publiczny dostęp Spotify Web API
dla pełnej sesji AMC: polskie streszczenie, potwierdzone fakty i zakresy,
listę danych właściciela, dowodów oraz plan późniejszego formalnego wniosku.
Aktualny kanał kontaktu i status kwotowy Client ID wymagają potwierdzenia.
Według rejestru nie kontaktowano się ze Spotify.

## Następny krok

Jeśli użytkownik wznowi temat, odnaleźć zachowany pakiet lub odtworzyć go
z aktualnych oficjalnych źródeł i istniejących rekordów Spotify. Przed
jakimkolwiek wysłaniem uzyskać od użytkownika zgodę na konkretną treść,
adresata i dane. To nie jest zadanie automatycznego kontaktowania Spotify.
